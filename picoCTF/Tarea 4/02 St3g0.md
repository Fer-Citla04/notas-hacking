## **Reto**:  St3g0
## **Descripción**
Download this image and find the flag.

- [Download image](https://artifacts.picoctf.net/c/216/pico.flag.png)
## **Solución**
1. Inicié con `exiftool -a -u pico.flag.png`
2. Verifiqué si el archivo PNG contenía otros archivos ocultos en su interior.
    `binwalk pico.flag.png`
3. Al confirmar que la estructura del archivo era íntegra seleccioné **`zsteg`**, una herramienta de Ruby diseñada  para analizar archivos PNG 
   `sudo gem install zsteg`
4. Luego : `zsteg -a pico.flag.png`
Y asi obtuve la bandera

```
picoCTF{7h3r3_15_n0_5p00n_a1062667}
```
