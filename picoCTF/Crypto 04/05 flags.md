## **Reto**:  flags
## **Descripción**
What do the [flags](https://challenge-files.picoctf.net/c_fickle_tempest/214c9d918be75903d4183c35fa4b94ef60dba05fc4df37c97cf0868087067372/flag.png) mean?
## **Solución**
1. Analizamos la imagen que contiene una serie de banderas de diversos colores y diseños de forma secuencial. 
2. Procedimos a realizar la traducción manual de cada bandera utilizando una tabla de referencia del alfabeto náutico:

- Las primeras banderas traducen la palabra: **PICOCTF**
    
- El contenido dentro de las llaves, siguiendo el mapeo alfabético y numérico, reveló la cadena: **F1AG5AND5TUFF**
```
picoCTF{F1AG5AND5TUFF}
```
## **Notas adicionales
- Código Internacional de Señales**: Es un sistema de signos visuales universalmente reconocido en la navegación. Aunque originalmente se diseñaron para la comunicación por radio o banderas físicas, en este tipo de retos de esteganografía se utilizan como un cifrado de sustitución visual.
