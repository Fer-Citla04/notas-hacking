## **Reto**: ASCII Numbers

## **Descripción**
Convert the following string of ASCII numbers into a readable string: `0x70 0x69 0x63 0x6f 0x43 0x54 0x46 0x7b 0x34 0x35 0x63 0x31 0x31 0x5f 0x6e 0x30 0x5f 0x71 0x75 0x33 0x35 0x37 0x31 0x30 0x6e 0x35 0x5f 0x31 0x6c 0x6c 0x5f 0x74 0x33 0x31 0x31 0x5f 0x79 0x33 0x5f 0x6e 0x30 0x5f 0x6c 0x31 0x33 0x35 0x5f 0x34 0x34 0x35 0x64 0x34 0x31 0x38 0x30 0x7d`

## **Solución**
1. Lo que hice, fue en un conversor poner todos los números hexa de la descripción y convertirlos a ascii. Metí todos, solo les quité el `0x`. Y así obtuve la bandera
2. Otra forma de hacerlo es por medio de python con el siguiente código:
`#Guardamos la cadena original`
`hex_string = "0x70 0x69 0x63 0x6f 0x43 0x54 0x46 0x7b 0x34 0x35 0x63 0x31 0x31 0x5f 0x6e 0x30 0x5f 0x71 0x75 0x33 0x35 0x37 0x31 0x30 0x6e 0x35 0x5f 0x31 0x6c 0x6c 0x5f 0x74 0x33 0x31 0x31 0x5f 0x79 0x33 0x5f 0x6e 0x30 0x5f 0x6c 0x31 0x33 0x35 0x5f 0x34 0x34 0x35 0x64 0x34 0x31 0x38 0x30 0x7d"`

` #Quitamos los "0x" y los espacios`
`clean_hex = hex_string.replace("0x", "").replace(" ", "")`

`#Convertimos de hexadecimal a texto`
`flag = bytes.fromhex(clean_hex).decode('ascii')`

`print(f"La bandera es: {flag}")`

Luego lo ejecutamos y así también obtenemos la bandera.

```
picoCTF{45c11_n0_qu35710n5_1ll_t311_y3_n0_l135_445d4180}
```

## **Notas adicionales**
- **`bytes.fromhex()`**: Es una función de Python que toma una cadena de números hexadecimales y la convierte en datos binarios .
- **`.decode('ascii')`**: Una vez que tenemos los bytes, le decimos a Python que los interprete como caracteres de la tabla ASCII para que podamos leerlos como texto normal.
- **Limpieza de datos**: En Python es importante quitar los espacios y los prefijos `0x` antes de procesar.
