1. Al intentar comandos básicos como `/bin/cat`, el sistema devolvía `No such file or directory`. Sin embargo, los **Wildcards** (`*`) y el comando `echo` seguían operativos, ya que `echo` es un comando integrado de la shell.
2. Sin el comando `ls`, utilicé `echo */*`para listar el contenido del directorio actual y directorios superiores.
3. En Bash, existe una sintaxis especial para leer el contenido de un archivo y pasarlo como argumento sin usar `cat`: **`$(< archivo)`**.
4. Al ejecutar `echo "$(< abra/cadabra.txt)"`, shell lee el archivo internamente y `echo` imprime el resultado.
5. El sistema respondió con _"Nothing up my sleeve!"_, validando que este método de lectura funcionaba.
6. Para evitar leer cada archivo manualmente, utilicé un bucle `for` en la línea de comandos. 
   for f in */*.txt; do echo "--- $f ---"; echo "$(< $f)"; done
