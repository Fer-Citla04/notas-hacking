## **Solución**
1. Para verificar si había un motor de plantillas procesando la entrada, probé una operación matemática simple encerrada entre dobles llaves: `{{ 7*7 }}`.

-  El servidor respondió con `49`.

1. En lugar de realizar operaciones aritméticas, utilicé una carga útil (_payload_) de Python diseñada para "romper" los límites del entorno restringido de la plantilla y acceder a las funciones del sistema operativo.

-**Payload:** `{{ self._TemplateReference__context.cycler.__init__.__globals__.os.popen('...').read() }}`
    

3. Una vez que obtuve acceso a la ejecución de comandos, utilicé el comando `ls` dentro del payload para listar los archivos presentes en el servidor.
4. Cambié el comando final a `cat flag` para que el servidor leyera el contenido del archivo secreto y lo imprimiera directamente en la respuesta HTML que mi navegador estaba visualizando.
