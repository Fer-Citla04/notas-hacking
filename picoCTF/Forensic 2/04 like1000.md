## **Reto**:   like1000
## **Descripción**
This [.tar file](https://challenge-files.picoctf.net/c_fickle_tempest/4e504d8229a455fa2c35c2c29c109d92388299b76a4fb323438c2b621a82e329/1000.tar) got tarred a lot.
## **Solución**
Al descargar el archivo `1000.tar`, al desempaquetarlo se obtenía otro archivo llamado `999.tar`, y al abrir ese, aparecía el `998.tar`. La pista del reto dice: "trata y haz un Script de esto y ahorrarás mucho tiempo", lo que el archivo fue empaquetado 1000 veces y que la bandera debe estar en el último nivel.
Por lo que, usando un Script se crea un ciclo for directamente en la terminal para que fuera desempaquetando cada archivo del 1000 al 1
`for i in {1000..1}; do tar -xvf $i.tar; done`
Y con esto, después con el comando `open flag.png`, dió la bandera de este reto

```
picoCTF{l0t5_0f_TAR5}
```

## **Notas adicionales
Otra solución:
Usando un Script de Python: el código abre el archivo, lo extrae y repite el proceso yendo hacia atrás en el rango de números:


`import tarfile`

`for i in range(1000, 0, -1):`
    `archivo = f"{i}.tar"`
    `print(f"Abriendo: {archivo}")`
    `with tarfile.open(archivo) as tar:`
        `tar.extractall()`
